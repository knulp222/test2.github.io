# Formation macOS

Supports de formation pour apprendre à utiliser un Mac au quotidien, du premier démarrage aux usages avancés.

## Public visé

- Personnes qui passent de Windows à macOS
- Débutants sur Mac
- Utilisateurs qui veulent gagner en efficacité (raccourcis, Spotlight, Terminal)

## Prérequis

- Un Mac sous macOS récent (les captures et menus correspondent à macOS 15 Sequoia et versions ultérieures)
- Un identifiant Apple (Compte Apple), conseillé mais pas obligatoire

Chaque module se termine par un petit exercice. Les exercices sont regroupés dans le dossier [exercices](exercices/README.md).

## Comment utiliser ces supports

1. Suivre les modules dans l'ordre (chacun s'appuie sur les précédents).
2. Faire les manipulations en même temps que la lecture.
3. Terminer par l'exercice du module avant de passer au suivant.

## Contribuer

Les modules sont de simples fichiers Markdown : pour corriger ou compléter un module, modifiez le fichier correspondant dans `modules/`.
