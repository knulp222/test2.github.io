# Module 3 — Réglages Système

**Objectifs :** trouver et modifier les principaux réglages du Mac.

## 1. Ouvrir les Réglages Système

- Menu  › **Réglages Système…**
- Ou Spotlight : `⌘ Espace` puis « Réglages ».

Astuce : le champ de **recherche** en haut de la barre latérale trouve un réglage sans connaître son emplacement.

## 2. Les réglages les plus utiles

| Rubrique | Ce qu'on y trouve |
|----------|-------------------|
| **Wi-Fi / Bluetooth** | Connexion aux réseaux et aux périphériques |
| **Général › Mise à jour de logiciels** | Mises à jour de macOS |
| **Général › Stockage** | Espace disque utilisé et recommandations |
| **Apparence** | Mode clair / sombre / automatique |
| **Bureau et Dock** | Taille et position du Dock, masquage automatique, coins actifs |
| **Écrans** | Résolution, disposition des écrans multiples, Night Shift |
| **Fond d'écran / Économiseur d'écran** | Personnalisation |
| **Notifications** | Autoriser ou non chaque application |
| **Son** | Sortie, entrée, sons d'alerte |
| **Clavier** | Raccourcis, sources de saisie, dictée |
| **Trackpad / Souris** | Vitesse, clic, gestes |
| **Utilisateurs et groupes** | Comptes du Mac |
| **Imprimantes et scanners** | Ajouter une imprimante |

## 3. Mises à jour

Réglages Système › Général › **Mise à jour de logiciels**. Activez les mises à jour automatiques de sécurité : elles corrigent des failles importantes.

## 4. Accessibilité

Réglages Système › **Accessibilité** : zoom, taille du texte, VoiceOver, contraste… À connaître pour adapter le Mac à chaque utilisateur.

## Exercice

1. Passez en mode sombre, puis revenez en mode automatique.
2. Réduisez la taille du Dock et activez son masquage automatique.
3. Vérifiez si une mise à jour de macOS est disponible.
4. Trouvez, grâce à la recherche, le réglage « Night Shift ».
