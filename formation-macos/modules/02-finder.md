# Module 2 — Le Finder et la gestion des fichiers

**Objectifs :** naviguer dans les dossiers, organiser ses fichiers, retrouver un document.

## 1. Qu'est-ce que le Finder ?

Le Finder est l'équivalent de l'Explorateur de fichiers de Windows. Son icône (visage bleu et blanc) est toujours la première du Dock.

## 2. La barre latérale

- **Favoris** : Applications, Bureau, Documents, Téléchargements…
- **iCloud** : iCloud Drive
- **Emplacements** : disques, clés USB, serveurs réseau
- **Tags** : étiquettes de couleur

Personnalisation : Finder › Réglages… › Barre latérale.

## 3. Les présentations

Menu Présentation ou `⌘ 1` à `⌘ 4` :

| Raccourci | Présentation |
|-----------|--------------|
| `⌘ 1` | Icônes |
| `⌘ 2` | Liste |
| `⌘ 3` | Colonnes |
| `⌘ 4` | Galerie |

## 4. Manipulations de base

| Action | Méthode |
|--------|---------|
| Nouveau dossier | `⌘ ⇧ N` |
| Renommer | Sélectionner puis `Entrée` |
| Copier / Coller | `⌘ C` / `⌘ V` |
| **Déplacer** (couper-coller) | `⌘ C` puis `⌘ ⌥ V` |
| Dupliquer | `⌘ D` |
| Mettre à la corbeille | `⌘ Suppr` |
| Aperçu rapide | Sélectionner puis `Espace` |
| Afficher les informations | `⌘ I` |
| Remonter au dossier parent | `⌘ ↑` |
| Afficher les fichiers cachés | `⌘ ⇧ .` |

> 💡 Sur Mac, `Entrée` renomme un fichier ; pour l'ouvrir, utilisez `⌘ ↓` ou un double-clic.

## 5. Retrouver un fichier

- Champ de recherche du Finder (`⌘ F`).
- **Spotlight** (`⌘ Espace`) cherche aussi dans le contenu des documents.
- **Tags** : clic droit › choisir une couleur, puis cliquer sur le tag dans la barre latérale.

## 6. La corbeille

Les fichiers supprimés vont dans la Corbeille (à droite du Dock). Clic droit sur la Corbeille › **Vider la Corbeille** pour les supprimer définitivement.

## Exercice

1. Dans Documents, créez un dossier `Formation macOS`.
2. Créez-y deux sous-dossiers : `Notes` et `Captures`.
3. Faites une capture d'écran (`⌘ ⇧ 3`) et déplacez-la du Bureau vers `Captures`.
4. Appliquez un tag vert au dossier `Formation macOS` et retrouvez-le via la barre latérale.
