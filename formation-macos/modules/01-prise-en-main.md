# Module 1 — Prise en main du Mac

**Objectifs :** reconnaître les éléments de l'écran, ouvrir et fermer des applications, allumer et éteindre le Mac correctement.

## 1. Les éléments de l'écran

| Élément | Emplacement | Rôle |
|---------|-------------|------|
| **Barre des menus** | En haut de l'écran | Menus de l'application active, menu Pomme , icônes d'état (Wi-Fi, batterie, son…) |
| **Menu Pomme ** | Coin supérieur gauche | Réglages Système, À propos de ce Mac, Suspendre, Redémarrer, Éteindre |
| **Dock** | En bas (par défaut) | Lanceur d'applications ; un point sous l'icône indique une app ouverte |
| **Bureau** | Fond d'écran | Fichiers posés sur le bureau, disques connectés |
| **Centre de contrôle** | Icône à droite de la barre des menus | Wi-Fi, Bluetooth, luminosité, volume, mode Concentration |
| **Centre de notifications** | Clic sur la date et l'heure | Notifications et widgets |

## 2. Ouvrir une application

Trois méthodes :

- Cliquer sur son icône dans le **Dock**.
- **Spotlight** : `⌘ Espace`, taper le début du nom, puis `Entrée`.
- Le dossier **Applications** dans le Finder.

## 3. Fermer une fenêtre ou quitter une application

Différence importante avec Windows :

- Le bouton rouge (ou `⌘ W`) **ferme la fenêtre**, mais l'application reste souvent ouverte (point sous l'icône du Dock).
- `⌘ Q` **quitte l'application**.
- Si une application ne répond plus : `⌘ ⌥ Échap` ouvre « Forcer à quitter ».

Les trois boutons en haut à gauche d'une fenêtre :

- 🔴 Fermer
- 🟡 Réduire dans le Dock
- 🟢 Plein écran (maintenir le clic pour les options de disposition en mosaïque)

## 4. Allumer, suspendre, éteindre

- **Suspendre** : menu  › Suspendre, ou fermer l'écran d'un portable. Idéal pour une courte pause.
- **Éteindre** : menu  › Éteindre…
- **Redémarrer** : menu  › Redémarrer… (utile après une mise à jour ou en cas de lenteur).

## 5. Connaître son Mac

Menu  › **À propos de ce Mac** : modèle, puce (Apple Silicon ou Intel), mémoire, version de macOS.

## Exercice

1. Ouvrez Calculette avec Spotlight.
2. Fermez sa fenêtre avec le bouton rouge : l'application est-elle encore ouverte ?
3. Quittez-la avec `⌘ Q`.
4. Notez la version de macOS et le type de puce de votre Mac.
