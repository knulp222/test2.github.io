# Module 4 — Raccourcis clavier et gestes du trackpad

**Objectifs :** connaître les touches de modification et les raccourcis essentiels pour travailler plus vite.

## 1. Les touches de modification

| Symbole | Touche | Équivalent Windows (approximatif) |
|---------|--------|-----------------------------------|
| `⌘` | Commande (cmd) | Ctrl |
| `⌥` | Option (alt) | Alt |
| `⌃` | Contrôle (ctrl) | — (clic droit avec `⌃` + clic) |
| `⇧` | Majuscule (shift) | Maj |
| `fn` / 🌐 | Fonction / Globe | Fn |

## 2. Raccourcis essentiels

| Raccourci | Action |
|-----------|--------|
| `⌘ C` / `⌘ X` / `⌘ V` | Copier / Couper / Coller |
| `⌘ Z` / `⌘ ⇧ Z` | Annuler / Rétablir |
| `⌘ A` | Tout sélectionner |
| `⌘ F` | Rechercher |
| `⌘ S` | Enregistrer |
| `⌘ P` | Imprimer |
| `⌘ N` | Nouveau document / nouvelle fenêtre |
| `⌘ T` | Nouvel onglet |
| `⌘ W` | Fermer la fenêtre ou l'onglet |
| `⌘ Q` | Quitter l'application |
| `⌘ Tab` | Passer d'une application à l'autre |
| `⌘ ,` | Réglages de l'application active |
| `⌘ Espace` | Spotlight |
| `⌘ ⌥ Échap` | Forcer à quitter |
| `⌃ ⌘ Q` | Verrouiller l'écran |

## 3. Captures d'écran

| Raccourci | Capture |
|-----------|---------|
| `⌘ ⇧ 3` | Tout l'écran |
| `⌘ ⇧ 4` | Une zone (puis `Espace` pour une fenêtre) |
| `⌘ ⇧ 5` | Outil complet : capture et enregistrement vidéo de l'écran |

## 4. Gestes du trackpad (réglages par défaut)

| Geste | Action |
|-------|--------|
| Toucher à deux doigts | Clic droit |
| Glisser à deux doigts | Défiler |
| Pincer à deux doigts | Zoom |
| Glisser à trois doigts vers le haut | Mission Control |
| Glisser à quatre doigts vers la gauche/droite | Changer de bureau |
| Écarter le pouce et trois doigts | Afficher le bureau |

La liste complète, avec vidéos de démonstration, se trouve dans Réglages Système › **Trackpad**.

## Exercice

1. Ouvrez Safari, créez trois onglets avec `⌘ T`, fermez-en un avec `⌘ W`.
2. Passez de Safari au Finder avec `⌘ Tab`.
3. Capturez uniquement la fenêtre de Safari (`⌘ ⇧ 4` puis `Espace`).
4. Ouvrez Mission Control avec le trackpad et créez un deuxième bureau.
