# Module 5 — Applications : installer, gérer, désinstaller

**Objectifs :** installer une application en toute sécurité, la mettre à jour et la supprimer.

## 1. Installer depuis l'App Store

1. Ouvrir l'**App Store**.
2. Rechercher l'application, cliquer sur **Obtenir** (ou le prix).
3. Confirmer avec le mot de passe du Compte Apple ou Touch ID.

C'est la méthode la plus sûre : les applications y sont vérifiées par Apple.

## 2. Installer depuis Internet

Toujours télécharger depuis le **site officiel de l'éditeur**.

- Fichier **.dmg** : l'ouvrir, puis glisser l'icône de l'application dans le dossier **Applications**. Éjecter ensuite le disque virtuel.
- Fichier **.pkg** : un installateur guidé ; suivre les étapes.

Au premier lancement, macOS peut afficher un avertissement. Si l'application est bloquée alors que vous êtes sûr de sa provenance : Réglages Système › **Confidentialité et sécurité**, puis **Ouvrir quand même**.

## 3. Mettre à jour

- Applications de l'App Store : App Store › **Mises à jour**.
- Autres applications : en général via le menu de l'application (« Rechercher les mises à jour… »).

## 4. Désinstaller

- La plupart des applications : glisser l'application du dossier Applications vers la **Corbeille**, puis vider la Corbeille.
- Applications de l'App Store : aussi possible depuis **Launchpad** (ou le nouvel écran Applications selon la version de macOS) en maintenant `⌥` puis en cliquant sur la croix.
- Certaines applications fournissent leur propre programme de désinstallation : l'utiliser en priorité.

## 5. Ouvrir un fichier avec une autre application

Clic droit sur le fichier › **Ouvrir avec**. Pour changer l'application par défaut : `⌘ I` › section « Ouvrir avec » › **Tout modifier…**.

## Exercice

1. Installez une application gratuite de l'App Store (par exemple Pages).
2. Ouvrez un fichier PDF avec Aperçu, puis avec Safari via « Ouvrir avec ».
3. Désinstallez l'application installée à l'étape 1.
