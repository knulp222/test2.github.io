## Quiz de fin de formation

1. Quelle est la différence entre `⌘ W` et `⌘ Q` ?
2. Comment déplacer (et non copier) un fichier au clavier dans le Finder ?
3. Où trouve-t-on les mises à jour de macOS ?
4. Quel raccourci ouvre l'outil complet de capture d'écran ?
5. Comment débloquer une application téléchargée sur Internet que macOS refuse d'ouvrir ?
6. Pourquoi iCloud Drive ne remplace-t-il pas complètement Time Machine ?
7. À quoi sert FileVault ?
8. Quelle commande du Terminal ouvre le dossier courant dans le Finder ?

<details>
<summary>Réponses</summary>

1. `⌘ W` ferme la fenêtre, `⌘ Q` quitte l'application.
2. `⌘ C` puis `⌘ ⌥ V`.
3. Réglages Système › Général › Mise à jour de logiciels.
4. `⌘ ⇧ 5`.
5. Réglages Système › Confidentialité et sécurité › Ouvrir quand même.
6. iCloud Drive synchronise : une suppression est répercutée partout ; ce n'est pas un historique complet de sauvegarde.
7. À chiffrer le disque pour protéger les données en cas de perte ou de vol.
8. `open .`

</details>
